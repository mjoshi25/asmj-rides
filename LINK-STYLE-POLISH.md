# ASMJ Ride — Link and navigation style polish

This update refines the visual hierarchy of navigation and text links without changing application workflows.

- Header navigation links have consistent sizing, spacing, hover and keyboard-focus states.
- Sign in is styled as a restrained outlined action; Create account/Register is the primary accent action.
- Footer links use consistent outlined chips with distinct but coordinated Sign in and Create account emphasis.
- Footer Logout uses a matching button treatment.
- Login/register helper links and Back to home control have improved hierarchy and contrast.
- CSS cache-busting version updated so deployed browsers request the latest stylesheet.

No Java, controller, model, repository, authentication, booking, payment, support-chat, or MongoDB configuration was changed.
