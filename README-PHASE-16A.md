# ASMJ Rides – Phase 16A

This release improves the Vehicle Owner / Travel Agent vehicle setup experience and adds explicit rental modes and vehicle availability management.

See `PHASE-16A-VEHICLE-SETUP-AND-AVAILABILITY.md` for scope, security checks, validation status and the remaining 16B–16E rental workflow plan.

Start from this project copy in a separate development folder. Run `mvn clean test` and then `mvn spring-boot:run` before any deployment. The live Render service is not modified by this ZIP.
